    This module provides modular access to all Korean martial arts techniques organized by trigram stance, plus Dark Ops techniques and configuration.

    Structure:

    • Individual stance files (Geon, Tae, Li, Jin, Son, Gam, Gan, Gon)
    • Dark Ops techniques for 암살자 archetype
    • Configuration and constants
