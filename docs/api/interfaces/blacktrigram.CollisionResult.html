    Interface CollisionResult

    Collision detection result.

    Korean: 충돌 결과

    Contains comprehensive information about a collision, including whether it hit, which region and vital point were struck, distance, and accuracy.

    Example

    const result: CollisionResult = {
      hit: true,
      region: "head",
      vitalPoint: templePoint,
      distance: 0.8,
      accuracy: 0.95
    };
