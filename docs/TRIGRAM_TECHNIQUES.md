# 팔괘 기술 체계 (Trigram Techniques System)

**Black Trigram (흑괘) - Korean Martial Arts Techniques Reference**

This document details the complete Korean martial arts technique system for the eight trigram stances, featuring authentic Hapkido (합기도), Taekwondo (태권도), Taekyon (택견), and Ssireum (씨름) techniques.

## 🔬 Technical Implementation

### Technique Structure
```typescript
interface KoreanTechnique {
  id: string;
  // Bilingual name structure (primary)
  name: {
    korean: string;
    english: string;
    romanized: string;
  };
  // Separate name fields (backward compatibility)
  koreanName: string;
  englishName: string;
  romanized: string;
  // Description in both languages
  description: {
    korean: string;
    english: string;
  };
  // Combat properties
  stance: TrigramStance;
  type: string;
  damageType: string;
  damage: number;
  kiCost: number;
  staminaCost: number;
  accuracy: number;
  range: number;
  executionTime: number;
  recoveryTime: number;
  critChance: number;
  critMultiplier: number;
  effects: readonly StatusEffect[];
}
```

**Note**: The interface maintains both `name` object and separate name fields (`koreanName`, `englishName`, `romanized`) for backward compatibility with existing code and tests.

### Accessing Techniques
```typescript
import { KoreanTechniquesSystem } from "@/systems/trigram/KoreanTechniques";
import { TrigramStance } from "@/types/common";

// Get all techniques for a stance
const geonTechniques = KoreanTechniquesSystem.getAvailableTechniques(
  TrigramStance.GEON
);

// Get primary technique for stance
const primaryTechnique = KoreanTechniquesSystem.getPrimaryTechnique(
  TrigramStance.LI
);

// Check if player can execute technique
const canExecute = KoreanTechniquesSystem.canExecuteTechnique(
  playerState,
  technique
);
```
