───────────────────────────────────────────────────────────────────────────────
  KEY OPTIMIZATIONS
───────────────────────────────────────────────────────────────────────────────

Pattern Used:
  const temp = ThreeObjectPools.vector3.acquire();
  try {
    temp.set(x, y, z);
    // Use temp for calculations
    const owned = temp.clone(); // Only if storing
  } finally {
    ThreeObjectPools.vector3.release(temp);
  }

Best Practices:
  ✓ Always use try-finally for pooled objects
  ✓ Acquire once, reuse in loops, release after
  ✓ Clone pooled objects when storing in structures
  ✓ Clear comments explaining pooling strategy
  ✓ Never pool component-owned objects

Objects Pooled:
  • Vector3: Position, velocity, direction calculations
  • Color: Material and particle color operations (available)
  • Euler: Rotation calculations (available)
  • Matrix4: Transformation calculations (available)
  • Quaternion: Rotation interpolation (available)

───────────────────────────────────────────────────────────────────────────────
  DETAILED ALLOCATION ANALYSIS
───────────────────────────────────────────────────────────────────────────────

ArterialSpray3D:
  Before: 4 Vector3 × 120-250 particles = 480-1000 allocations
  • dir.clone()
  • new Vector3(0, 1, 0).cross(dir).normalize()
  • velocity rotations
  
  After: 4 pooled vectors reused across all particles
  • tempDir, tempAxis, tempUp, tempVel
  • Cloned only for storage in particle array

NerveStrikeParticles3D:
  Before: 1 Vector3 × 40-80 particles + per-frame calculations
  • Direction normalization in loop
  • Target position calculations each frame
  
  After: 1 pooled vector in init + 3 pooled vectors per frame
  • tempDir for initialization
  • tempTarget, tempDelta, effectPos for animation

HitFeedbackEffect3D:
  Before: 1 Vector3 × 25-80 particles
  • Velocity calculations in seeded random loop
  
  After: 1 pooled vector for all particles
  • tempVel reused for all velocity calculations

TrainingHitEffects3D:
  Before: 2 Vector3 × 10-30 particles
  • new Vector3(0, 0, 0) for position
  • new Vector3(x, y, z) for velocity
  
  After: 1 pooled vector for velocity calculations
  • tempVel reused, cloned for storage
